Esta área é opcional. Para usar no Gmail, normalmente basta clicar em Copiar assinatura formatada. O código é útil para quem quiser editar, estudar ou integrar a assinatura em outro sistema.

Como usar: preencha seus dados e clique em Copiar assinatura formatada. Para a maioria das pessoas, não é necessário visualizar nem editar o HTML. Depois, no Gmail, acesse Configurações → Ver todas as configurações → Geral → Assinatura e cole.

Foto: ao carregar uma imagem do computador, o gerador cria automaticamente uma cópia leve, quadrada e otimizada para a assinatura. A imagem original não é enviada para nenhum servidor. Uma URL pública continua disponível apenas como alternativa.

Sobre o projeto

Este gerador nasceu da ideia de simplificar a criação de assinaturas profissionais de e-mail para estudantes, profissionais em início de carreira, candidatos a vagas e pessoas que desejam fortalecer sua identidade digital sem precisar editar HTML manualmente.

A ferramenta permite preencher dados pessoais, gerar automaticamente links de WhatsApp, e-mail e LinkedIn, personalizar cores, visualizar o resultado em tempo real e copiar ou baixar o HTML final. A versão 1.3.6 também otimiza automaticamente fotos carregadas pelo computador e utiliza uma estrutura de contatos mais estável em telas menores, mantendo foco em compatibilidade com o Gmail.

O projeto também funciona como um exercício prático de aplicação de Prompt Engineering e uso de IA generativa para transformar uma necessidade real em uma solução funcional.
